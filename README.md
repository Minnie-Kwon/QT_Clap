# 큐티로봇 짝짝 리듬

음악에 맞춰 큐티로봇과 박수를 치는 터치 리듬 게임이에요. 웹캠은 필요 없어요.

## 실행

1. 압축을 풀고 `start.bat` 더블클릭 → 브라우저가 자동으로 열려요 (검은 창은 켜 둔 채로)
2. 난이도를 고르면 노래가 시작돼요
3. 인터넷 연결이 필요해요 (three.js를 인터넷에서 불러옴)

휴대폰에서 하려면 폴더째 Netlify, Vercel, GitHub Pages 같은 곳에 올려서 https 주소로 여세요.

## 하는 법

**처음이면 "연습하기"부터!** 느린 노래(반짝반짝 작은별, 92 BPM)에 판정이 넉넉하고, 왼손 → 오른손 → 양손 → 섞어서 순서로
안내 문구가 나오고, 쳐야 할 패드가 통통 튀어요. 연습 점수는 최고 점수에 저장되지 않아요.

| 단계 | 노래 | 빠르기 | 한 판 | 특징 |
|---|---|---|---|---|
| 연습하기 | 반짝반짝 작은별 | 92 BPM | 약 70초 | 안내 문구, 판정 넉넉, 점수 저장 안 함 |
| 아주 쉬움 | 비행기 | 100 BPM | 약 65초 | 한 마디에 박수 1~2번, 판정 넉넉 |
| 쉬움 | 나비야 | 112 BPM | 약 75초 | 정박 박수 |
| 보통 | 런던 다리 | 120 BPM | 약 70초 | 엇박 등장 |

노래는 모두 오래된 전래·공개 동요 멜로디예요 (반짝반짝 작은별: 18세기 프랑스 민요, 비행기: 1830년대 미국 동요,
나비야: 19세기 독일 민요, 런던 다리: 영국 전래 동요). 음악 파일 없이 코드로 연주해요.

- 큐티가 손을 내밀면 손바닥 쪽에 **링이 줄어들어요**. 링이 손바닥 크기가 되는 순간 터치!
- 화면 **왼쪽** = 왼손 (분홍), **오른쪽** = 오른손 (파랑), **가운데** 또는 **두 손가락 동시** = 양손 (노랑)
- 큐티가 혼자 박수 칠 때는 쉬는 박자예요
- 키보드: ← 또는 F / Space / → 또는 J, Esc = 그만
- 박자가 계속 밀리면 시작 화면의 **타이밍 조절**을 움직여 보세요 (블루투스 이어폰은 소리가 늦게 나요)

| 판정 | 범위 | 점수 |
|---|---|---|
| Perfect | ±0.075초 | 100 |
| Good | ±0.15초 | 60 |
| Miss | 그 밖 / 반대 손 | 0, 콤보 끊김 |

콤보 10개마다 점수 10% 보너스. 정확도 90% 이상이면 별 3개.

**큐티 목소리**: Perfect면 "대단해", Good이면 "잘했어", Miss면 "다시"라고 말해요 (`voices/` 폴더의 녹음 파일).
박수가 빠르게 이어질 때는 말이 겹치지 않도록 앞의 말이 끝날 때까지 건너뛰어요 (Miss는 항상 말해요).

## 파일 구조

```
index.html   화면 (시작·게임·결과 화면, 버튼)
game.js      게임 전체 (로봇 포즈, 악보, 판정, 효과, 루프)
music.js     반주와 효과음을 코드로 연주하는 곳 (음악 파일 없음)
songs.js     동요 멜로디와 코드 (음이름:박자로 적혀 있어요)
park.js      놀이터 배경 (Robot Mirror와 같음)
voices/      큐티 목소리 (perfect = 대단해, good = 잘했어, miss = 다시)
models/      큐티로봇 FBX + 텍스처
```

## 바꿔 보기

- **새 악보 만들기**: `game.js`의 `LEVELS`. 마디 모양(`bars`)을 정하고, `seq`에 마디 순서를 글자로 적어요.
  `[박자 위치, 종류]` — 종류는 `S`(로봇 혼자), `L`, `R`, `B`(양손). 박자 위치 0.5는 엇박이에요.
- **노래 바꾸기**: `songs.js`에 멜로디를 `'C5:1 C5:1 G5:2'`처럼 적고(음이름:박자), `LEVELS`의 `tune`에 연결해요. 빠르기는 `bpm`
- **판정 넓히기**: `JUDGE` 값을 키우면 쉬워져요 (연습하기·아주 쉬움은 `JUDGE_PRACTICE`)
- **목소리 바꾸기**: `voices/` 폴더의 mp3를 같은 이름으로 바꿔 넣으면 돼요 (`game.js`의 `VOICE_FILES`)
- **로봇 포즈**: `POSE_DEFS`에서 윗팔·아랫팔·손 방향 (x 좌우, y 위아래, z 앞쪽)
